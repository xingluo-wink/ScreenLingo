# 屏译 ScreenLingo 0.3.1

Windows 框选翻译工具：本地识别中英文，使用你配置的 API 翻译，在可拖动、可缩放的阅读窗口中显示译文。

## 开始使用

1. 完整解压软件文件夹，运行 `ScreenLingo.exe`。需要 Windows x64，建议 Windows 11；不需要额外安装 Python、.NET 或 OCR 环境。
2. 在「翻译 API」中填写接口类型、API 地址、API Key、模型名称。模型名称在表单下方，小窗口中可滚动查看。
3. 点击「测试翻译」，确认连接成功，再点击「保存并使用」。支持保存多套配置，选择后点击「保存并使用」切换。
4. 按 **Ctrl+Alt+Q**，拖动框选文字，松开鼠标后点击 **中文**、**English** 或 **双语**。
5. 按 **Esc** 退出选区。关闭设置窗口后软件继续在托盘运行；右键托盘的「译」图标，选择「退出屏译」才完全退出。

截图保存是独立功能，不要求先配置或调用翻译 API。默认不会将截图或识别原文写入磁盘。

**一次框选就是一个翻译整体**：识别文字按从上到下、同一行从左到右拼接，整段发送和显示，不再按 OCR 行框自动拆成多个翻译块。需要翻译局部时，直接缩小框选范围。

## 选区操作

| 操作 | 用法 |
|---|---|
| 中文 / English / 双语 | 顶部三选一，或按 C / E / B；当前模式高亮 |
| 移动 / 调整窗口 | 拖动系统标题栏 / 拖动窗口边缘，支持最大化 |
| 调整字号 | A− / A＋、字号菜单（12–40），或正文上 Ctrl+滚轮 |
| 查看原图 | 点击「原图」或按 O；按住空格临时查看 |
| 返回正文 | 点击「正文」或按 R |
| 复制 | 正文可跨段划选；Ctrl+C 或「复制」复制选中文字，没有选择时复制当前正文 |
| 置顶 / 适应内容 | 「更多」菜单 |
| 双语左右对照 | 「更多 → 双语左右对照」，宽窗口时生效 |
| 双语联动高亮 | 左键拖选中文或英文，另一语言中对应的词组自动高亮；底部也显示对应文字 |
| 原图布局预览 | 「更多」菜单；放不下完整译文时保留完整阅读 |
| 保存原图 | 「更多 → 保存原图」，或 Ctrl+S |
| 保存完整译图 | 「更多 → 保存完整译图」，或 Ctrl+Shift+S |
| 停止 / 重试 | 翻译时底部显示「停止」，停止或出错后显示「重试」 |
| 关闭阅读窗口 | Esc 或系统关闭按钮，主程序仍驻留托盘 |

工具条和正文处在同一个可移动、可缩放的窗口内。初次打开根据选区选择适合阅读的尺寸；手动移动或调整大小后，翻译更新和字号变化不再重置窗口。窗口尺寸、字号、双语布局和置顶偏好会保存。原图在当前窗口中按比例预览，不改变窗口的位置与大小。

双语默认完整英文在上、中文在下。可在更多菜单启用左右对照（左英文、右中文）；窗口较窄或字号较大时，自动使用上下对照。正文可连续划选复制，单击不会再弹出额外对话框。

翻译等待期间保留识别原文或已有的完整译文，尽量保持选区和阅读位置。较长内容使用整个正文区域滚动，不把文字压进截图的小框。保存完整译图会导出滚动区域之外的全部内容，并保留当前字号及双语布局。

通用模型首次双语先生成并显示完整中英文，再单独补充词组对应关系；如果某个语言已翻译，会保留并复用现有正文。词组对应关系只用于高亮，不会把正文拆开。左键拖选任一语言，另一语言中有对应关系的词组会同步高亮，支持重复词、语序不同和跨行选取。高亮按模型给出的词组粒度显示，准确度取决于模型。

对应关系使用精简的数据格式。如果高亮结果被截断，会用更少的词组自动重试一次，保持你配置的输出上限。高亮超时、截断或格式不正确时，已经完成的双语正文仍可阅读和复制；点击「重试高亮」只补充对应关系，不重新翻译正文。生成高亮过程中也可以停止，保留完整译文。较长内容的词组对应可能更粗，准确度取决于模型。

生成对应关系需要单独的 API 请求；生成后，选词和高亮完全在本地执行，不新增请求。如果正文自身仍被截断，可在 API 高级设置中提高输出 Token 上限。同一模式翻译进行中，重复点击不会重启请求。切换字号、移动窗口、查看原图不会调用 API；关闭阅读窗口后缓存即丢弃。

## API 配置

软件不预置密钥、模型或余额，不绑定任何服务商。请按服务商给出的协议选择，兼容接口通常选 Chat Completions。

| 类型 | 请求路径 | 地址填写规则 |
|---|---|---|
| Chat Completions | `/chat/completions` | 一般填写以 `/v1` 结尾的基础地址 |
| Responses | `/responses` | 一般填写以 `/v1` 结尾的基础地址 |
| Anthropic Messages | `/messages` | 一般填写以 `/v1` 结尾的基础地址 |
| Gemini GenerateContent | `/models/{模型}:generateContent` | 官方接口一般填写以 `/v1beta` 结尾的基础地址 |
| Qwen-MT | `/chat/completions` | 使用服务商的兼容地址和专用翻译模型 ID |

也可填写对应的完整请求 URL，软件会避免重复拼接后缀。HTTPS 为默认要求，本机 `http://localhost` / `127.0.0.1` 接口可用。API Key 使用当前 Windows 用户的 DPAPI 加密保存在程序目录 `data/settings.json`，更换电脑或 Windows 用户后需要重新填写密钥。

「高级设置」提供超时、输出 Token 上限、翻译风格和额外 JSON 参数。不同模型所需的参数可自行填写，例如 `{"temperature":0.2}`。软件保留对输入、模型、目标语言、非流式请求等字段的控制。一般模型需能返回完整 JSON；返回缺块、空内容或被截断时会显示错误，不会悄悄把遗漏当作成功。

Qwen-MT 使用专用翻译参数，将整个选区作为一段翻译；双语分别请求两个语言。此接口目前只提供整段翻译，不提供联动高亮的词组对应关系。联动高亮支持 Chat Completions、Responses、Anthropic Messages 和 Gemini GenerateContent 接口，需要所配模型能够遵循 JSON 输出要求。

点击目标语言时，**仅识别出的选区文字**发送到当前配置的 API；截图不上传。「测试翻译」发送软件自带的固定测试句。API 服务本身的数据处理规则取决于你选择的服务商。

## 运行占用

采用 C# / WPF 原生桌面界面、CPU 本地 OCR、独立识别进程，无浏览器内核和本地大语言模型。OCR 使用 PP-OCRv5 中英文移动模型。

- 默认闲置 2 分钟释放整个 OCR 进程，可设置为 30 秒、1 分钟或 5 分钟。
- 托盘菜单或性能设置中可以立即释放 OCR 内存。下一次框选会自动重新加载。
- 本机 1200×720 规则文字样本，首轮 OCR 约 1 秒，连续识别约 0.6–0.8 秒。实际受选区尺寸、文字量和硬件影响。
- 完整使用后的一次待机样本：主程序私有驻留约 85 MiB、总工作集约 247 MiB、CPU 0%。两种内存口径不同；设置页显示总工作集。识别过程中会额外占用内存，详细数据见测试报告。
- 云端翻译耗时、费用和翻译水平由你配置的模型与网络决定，本地测试接口的响应时间不代表真实服务。

## 当前边界

适用于网页、文档、软件界面的横排中英文规则文字。极小字、模糊内容、倾斜文字、复杂表格、公式和复杂图片背景仍可能识别或分段错误；没有承诺所有文字都能无误识别。

原图布局预览以背景色覆盖文字区域，不做图片背景修复。检测到译文放不下时自动保留完整阅读，避免裁字。软件显示的是框选时刻的截图，不能修改底层网页或应用，也不会随它们滚动。受保护的视频、系统安全桌面、独占全屏应用可能截不到。

已实测 Windows 11、2560×1440 主屏；多屏负坐标和 DPI 转换已有实现，但混合缩放的多屏组合尚未实机覆盖。第一版面向个人使用，未做代码签名、自动更新或开机自启动。

## 源码与构建

发布目录为 `release/ScreenLingo`。源码仓库包含 OCR 模型与字典，可直接克隆后构建。

源码结构：`ScreenLingo` 为窗口和系统集成；`ScreenLingo.Core` 为选区拼接、协议、翻译与词组对应关系；`ScreenLingo.Ocr` 为独立识别进程；`ScreenLingo.Tests` 为本地验证。

安装 .NET 10 SDK，然后执行 `powershell -ExecutionPolicy Bypass -File .\build.ps1 -Publish`。仓库不包含 SDK、NuGet 缓存、用户配置和测试临时文件。首次恢复依赖需要联网。

测试命令：`dotnet run --project src/ScreenLingo.Tests -c Release -- <项目根目录>`。正式构建先于测试，因为测试调用发布目录中的 OCR 程序。

依赖及模型来源见 `THIRD-PARTY.md`，许可证见 `licenses`。
